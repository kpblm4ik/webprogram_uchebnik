# webprogram_uchebnik

Интерактивный учебник по веб-программированию. Страницы — обычные `.md`, терминал для практики вставляется блоком ```` ```term ````.

## Структура

```
index.html          — главная (титул, описание, кнопки курсов)
book.html           — читалка учебника (book.html?c=html#1)
css/style.css       — вид учебника и терминала
css/home.css        — вид главной и ссылки «Главная»
js/courses.js       — список курсов и цветов кнопок
js/home.js          — рисует кнопки на главной
js/app.js           — листание, анимация слов
js/markdown.js      — безопасный Markdown -> DOM (без innerHTML)
js/terminal.js      — терминал (class="term")
courses/<id>/page1.md, page2.md, ...  — страницы курса
```

Курсы: `html`, `css`, `python`, `js`, `cpp`, `rust`, `bash`, `wgsl`, `asm`.

## Как добавить страницу

Создай `courses/<id>/page2.md`, `page3.md` и т.д. Кнопка → появится сама, когда следующий файл существует.

## Как добавить курс

1. Добавь строку в `js/courses.js` (id, название, цвет окантовки).
2. Создай `courses/<id>/page1.md`.

Поддерживается: `# заголовки` (до 4 уровней), абзацы, `**жирный**`, `*курсив*`, `` `код` ``, блоки кода, списки, цитаты `>`, `---`, ссылки `[текст](url)`, картинки `![описание](images/a.png)`.

## Терминал

````
```term
task: Введи команду, которая выводит hello
prompt: $
ok: echo hello => hello
warn: echo => Warning: nothing to print (Предупреждение: нечего выводить)
err: echo hi => Error: wrong text (Ошибка: неверный текст)
default: bash: {cmd}: command not found (bash: {cmd}: команда не найдена)
```
````

- `task:` — подпись над терминалом; `prompt:` — приглашение (до 10 символов, по умолчанию `$`).
- `ok:` / `warn:` / `err:` — `команда => вывод`. Рамка станет зелёной / жёлтой / красной. Команда не должна содержать `=>` (в JS не используй стрелочные функции).
- `default:` — ответ на неизвестную команду (`{cmd}` подставится как текст).
- `\n` внутри вывода — перенос строки.
- Формат сообщений: **английский текст (русский перевод)** — перевод в скобках в конце.
- Рамка оранжевая, пока ничего не введено; при новом наборе снова оранжевая. Вывод прилетает плашкой над терминалом в оранжевой рамке.

## Защита терминала

- Терминал **ничего не выполняет**: ввод только сравнивается со списком команд из `.md`.
- Ввод и вывод попадают на страницу только через `textContent` — никакого `innerHTML`, `eval`, `Function`.
- HTML внутри `.md` не исполняется, а показывается как текст; ссылки и картинки — только `http(s)` и относительные.
- Лимиты: ввод 200 символов, без управляющих символов, не чаще одной отправки в 250 мс, до 40 правил на терминал.
- Сопоставление через `Map`; курс в адресе проверяется по белому списку, номер страницы — только число.
- Content-Security-Policy: скрипты и стили только со своего сайта, без inline-кода.

## Запуск

Нужен веб-сервер (из-за `fetch`): включи GitHub Pages для `main` или локально (например, в Termux): `python -m http.server 8000`, затем открой `http://localhost:8000`.

## Анимация

Слова, терминалы и картинки при листании плавно опускаются вниз и затухают по очереди; новая страница появляется так же (слова опускаются на место сверху). Чтобы появление шло снизу вверх, в `css/style.css` поменяй знак у `translateY(-14px)` в `.entering .unit`.
