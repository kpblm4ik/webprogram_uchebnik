# webprogram_uchebnik

Каркас веб-учебника. Страницы — обычные `.md`, терминал для практики вставляется блоком ```` ```term ````.

## Структура

```
index.html        — оболочка (кнопки ← →, контейнер страницы, CSP)
css/style.css     — весь внешний вид (белый фон, чёрный текст, оранжевые рамки)
js/app.js         — листание, анимация слов
js/markdown.js    — безопасный Markdown → DOM (без innerHTML)
js/terminal.js    — терминал (class="term"), сообщения на русском в скобках
pages/page1.md    — тестовая страница
```

## Как добавить страницу

Создай `pages/page2.md`, `pages/page3.md` и т.д. Больше ничего менять не нужно:
кнопка → появится сама, когда следующий файл существует. Страницы открываются по адресу `#1`, `#2`, …

Поддерживается: `# заголовки` (до 4 уровней), абзацы, `**жирный**`, `*курсив*`, `` `код` ``,
блоки кода, списки (`-` и `1.`), цитаты `>`, `---`, ссылки `[текст](url)`, картинки `![описание](images/a.png)`.

## Терминал

````
```term
task: Введи команду, которая выводит hello
prompt: $
ok: echo hello => hello
warn: echo => Warning: nothing to print (Предупреждение: нечего выводить)
err: echo hi => Error: wrong text (Ошибка: неверный текст)
default: bash: {cmd}: command not found (bash: {cmd}: команда не найдена)
```
````

- `task:` — подпись над терминалом.
- `prompt:` — символ приглашения (по умолчанию `$`).
- `ok:` / `warn:` / `err:` — `команда => вывод`. Рамка терминала станет зелёной / жёлтой / красной.
- `default:` — ответ на неизвестную команду (необязательно; `{cmd}` подставится как текст).
- `\n` внутри вывода — перенос строки.
- Формат сообщений: **английский текст (русский перевод)** — перевод в скобках в конце.
- Рамка оранжевая, пока ничего не введено; при новом наборе текста снова становится оранжевой.
- Вывод прилетает плашкой над терминалом, тоже в оранжевой рамке.

## Защита терминала

- Терминал **ничего не выполняет**: ввод только сравнивается со списком команд из `.md`.
- Ввод и вывод попадают на страницу только через `textContent` — никакого `innerHTML`, `eval`, `Function`.
- HTML внутри `.md` не исполняется, а показывается как текст; ссылки и картинки — только `http(s)` и относительные (`javascript:` блокируется).
- Ограничения: длина ввода 200 символов, управляющие символы запрещены, не чаще одной отправки в 250 мс, до 40 правил на терминал.
- Сопоставление идёт через `Map` (нельзя подсунуть `__proto__`, `constructor`).
- Content-Security-Policy в `index.html`: скрипты и стили только со своего сайта, без inline-кода.

## Запуск

Нужен веб-сервер (из-за `fetch`): включи GitHub Pages для ветки `main` или локально
(например, в Termux): `python -m http.server 8000`, затем открой `http://localhost:8000`.

## Анимация

Слова, терминалы и картинки при листании плавно опускаются вниз и затухают слово за словом; новая страница появляется так же
(слова опускаются на своё место сверху). Чтобы появление шло снизу вверх, в `css/style.css` поменяй знак у `translateY(-14px)` в `.entering .unit`.
