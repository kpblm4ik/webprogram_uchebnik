# Страница 1. Привет, терминал

Это тестовая страница учебника. Текст пишется обычным **Markdown**, а ниже — терминал для практики. Листай кнопками ← и → или стрелками на клавиатуре.

## Задание 1

Введи команду `echo hello` — она выводит слово hello. Нажми Enter.

```term
task: Выведи слово hello
prompt: $
ok: echo hello => hello
warn: echo => Warning: nothing to print (Предупреждение: нечего выводить)
err: echo hi => Error: expected "hello" (Ошибка: ожидалось «hello»)
```

## Задание 2

Узнай, в какой папке ты находишься: команда `pwd`. Попробуй сначала ошибиться — рамка станет красной, потом введи правильно — зелёной.

```term
task: Покажи текущую папку
prompt: $
ok: pwd => /home/student
warn: ls => Warning: this lists files, not the path (Предупреждение: это список файлов, а не путь)
```

> Любая другая команда даст ошибку на английском с переводом на русский в скобках — так привыкаешь к настоящим терминалам.
