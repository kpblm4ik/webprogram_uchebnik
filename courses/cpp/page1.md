# C++. Страница 1. Вывод на экран

C++ — компилируемый язык: код сначала превращается в программу, и только потом запускается. Вывод на экран делает объект `std::cout` с оператором `<<`. Каждая команда заканчивается точкой с запятой.

## Задание

Выведи слово Привет.

```term
task: Выведи Привет через std::cout
prompt: c++>
ok: std::cout << "Привет"; => Привет
warn: std::cout << 'Привет'; => warning: multi-character constant (предупреждение: многосимвольная константа)
err: cout << "Привет"; => error: 'cout' was not declared in this scope (ошибка: «cout» не объявлен в этой области видимости; нужно std::cout)
err: std::cout << "Привет" => error: expected ';' at end of statement (ошибка: ожидалась «;» в конце команды)
default: error: expected expression (ошибка: ожидалось выражение)
```
