# JS. Страница 1. Первое сообщение

JavaScript оживляет страницы в браузере. Команда `console.log()` печатает сообщение в консоль — главный инструмент отладки. Каждую команду принято заканчивать точкой с запятой.

## Задание

Выведи в консоль слово Привет.

```term
task: Выведи Привет через console.log
prompt: js>
ok: console.log("Привет"); => Привет
warn: console.log("Привет") => Привет\nWarning: semicolon is missing (Предупреждение: нет точки с запятой)
err: console.Log("Привет"); => TypeError: console.Log is not a function (TypeError: console.Log не является функцией)
default: Uncaught SyntaxError: unexpected input (Uncaught SyntaxError: неожиданный ввод)
```
