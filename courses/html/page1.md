# HTML. Страница 1. Первый тег

HTML — язык разметки: он говорит браузеру, что есть на странице — заголовок, абзац, картинка. Разметка состоит из **тегов**. Большинство тегов парные: открывающий `<h1>` и закрывающий `</h1>`, а текст — между ними.

Тег `<h1>` — заголовок первого уровня, самый крупный.

## Задание

Напиши заголовок первого уровня с текстом Привет.

```term
task: Напиши заголовок h1 с текстом Привет
prompt: html>
ok: <h1>Привет</h1> => Done: heading "Привет" is shown (Готово: заголовок «Привет» показан)
warn: <h1>Привет => Warning: tag is not closed (Предупреждение: тег не закрыт)
err: <h2>Привет</h2> => Error: wrong heading level, expected h1 (Ошибка: неверный уровень заголовка, нужен h1)
default: Error: unknown markup "{cmd}" (Ошибка: непонятная разметка «{cmd}»)
```

> Попробуй сначала ошибиться — рамка станет красной или жёлтой, а потом введи правильно.
