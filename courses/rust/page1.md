# Rust. Страница 1. Привет, мир

Rust — быстрый и безопасный язык. Вывод на экран делает **макрос** `println!` — у макросов в конце имени стоит восклицательный знак. Команды заканчиваются точкой с запятой.

## Задание

Выведи слово Привет.

```term
task: Выведи Привет через println!
prompt: rust>
ok: println!("Привет"); => Привет
warn: let x = 5; => warning: unused variable: `x` (предупреждение: неиспользуемая переменная «x»)
err: println("Привет"); => error: expected function, found macro `println` (ошибка: ожидалась функция, найден макрос «println»; добавь !)
default: error: expected one of `;` or `}` (ошибка: ожидалась « ; » или « } »)
```
