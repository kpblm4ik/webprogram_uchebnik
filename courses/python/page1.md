# Python. Страница 1. Первая программа

Python читается почти как английский. Функция `print()` выводит текст на экран. Текст пишется в кавычках.

## Задание

Выведи слово Привет.

```term
task: Выведи Привет с помощью print
prompt: >>>
ok: print("Привет") => Привет
warn: print("Привет"); => Привет\nWarning: semicolon is not needed in Python (Предупреждение: точка с запятой в Python не нужна)
err: Print("Привет") => NameError: name 'Print' is not defined (NameError: имя «Print» не определено)
err: print(Привет) => NameError: name 'Привет' is not defined (NameError: имя «Привет» не определено, забыл кавычки?)
default: SyntaxError: invalid syntax (SyntaxError: неверный синтаксис)
```
