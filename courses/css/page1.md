# CSS. Страница 1. Первое правило

CSS — язык оформления: цвета, размеры, отступы. Правило состоит из **селектора** (кого красим) и блока в фигурных скобках со **свойствами**: `свойство: значение;`.

Правило `h1 { color: orange; }` красит все заголовки h1 в оранжевый.

## Задание

Напиши правило, которое красит h1 в оранжевый цвет.

```term
task: Покрась h1 в оранжевый
prompt: css>
ok: h1 { color: orange; } => Applied: h1 is orange (Применено: заголовок h1 оранжевый)
warn: h1 { color: orange } => Warning: last semicolon is missing, better add it (Предупреждение: нет последней точки с запятой, лучше её поставить)
err: h1 { colour: orange; } => Error: unknown property "colour" (Ошибка: неизвестное свойство «colour»)
default: Error: invalid rule "{cmd}" (Ошибка: неверное правило «{cmd}»)
```
